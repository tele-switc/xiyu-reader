# 词汇量测试 v3 · 等值校准与区间标定报告 · 2026-09-30

修复对象：`docs/state-2026-09-30.md` ②#5——界面标称「95% 置信区间」，
但交付区间在 N=3000 虚拟人群上实测覆盖只有 **64.0%**（本轮复算为 63.2%，见 §4）。
方法见 `docs/notes/NOTES.md`「参考实现 · 第二轮」：点估计在**等值之前**的原始估计上拟线性等值线，
区间宽度 = 后验半宽形状 × 共形放大系数（含 `(1+1/n)` 有限样本修正），
拟合折与验证折种子不重叠；名义置信水平 95% 是判据，**未做任何反向调整**。

## 1. 拟合命令与产物常量

```bash
node tools/simulate-test.cjs 3000 --fit            # 拟合折种子基址 1000，验证折 500000
node tools/simulate-test.cjs 3000 --seedbase=900000 # 完全独立的第三批复算
```

写回 `app-src/resources/js/teststat.js` 的交付常量：

```js
const EQUATE = { a: 1.1795, b: -2428.9, ciK: 1.0988, fittedAt: '2026-09-30', n: 3000 };
```

交付公式不变：点估计 `equate(V̂_raw) = round((a·V̂_raw + b)/50)·50`，
区间 = 点估计 ± `ciK·a·后验半宽` 外扩取整到 50（`teststat.js` 的 `equate()/interval()`）。

## 3. 结论

- **覆盖率修复成立**：交付区间实测 94.6% / 95.2%（两批样本外），对比修复前的 64.0%。
  界面「95% 置信区间」这句话现在是经验可复现的，不只是名义值。
- **点估计无系统偏差**：三批偏差 +24 / +21 / 0 词（修复前应用侧真实偏差为 -145 词，state ②#4）。
- **代价是区间变宽**：平均宽度从 3345 词 → 约 4010 词。这是把假窄区间诚实化的必然结果，不是回归。
- 对照旧算法：同一验证折上 v2 偏差 -317 / MAE 1281 / RMSE 1602 / P90 2683，
  v2 MAE 为 v3 的 **1.54 倍**，且 v2 没有区间可报。

## 4. 64% 这个数字的来源复现（诊断）

`--fit` 输出中的旧构造对照（同一批 3000 人、同一份验证折）：

> 端点各自等值（中心≠点估计）: 覆盖 **63.2%** | 平均宽度 3335 词 | 区间中心比点估计平均偏 **-1067** 词

即：旧构造把 `rawLo/rawHi` 各自过等值线，区间中心偏离点估计一千多词，
且后验半宽本身偏窄（未标定 ciK）——两个毛病叠加导致标称 95%、实测 64%。

## 5. 如实记录的保留事项

- **最高真值段覆盖仍不达标**：独立复算 D9（真值约 16000–18000 词）覆盖只有 **80%**，
  验证折同段为 96%——两批不一致，说明该段（每段约 300 人以下）估计本身在波动，
  顶部水平的学习者区间仍偏乐观。未通过加宽系数硬凑（那会牺牲其余九段的区间宽度）。
- 真值模型是模拟器（带掌握率 logistic 曲线 + 自查过度自信 + 1/4 猜对率），
  「95%」的经验保证只在模型假设成立的范围内有效；真实人群偏离模型时需要用真人的留出样本重标。
- 换题库、换题型比例或改先验形状（`PRIOR`、`COG_ADD`、`SELF_W`）后必须重跑 §1 的两条命令，
  本报告与 `EQUATE` 常量即作废。

## 7. 第四轮 · 交付路径独立复算（2026-09-30，只验证、未改任何常量与判据）

复算方式：不重跑 `--fit`（重拟会覆盖已落库常量），直接按 `teststat.js` 当前
`EQUATE = { a: 1.1795, b: -2428.9, ciK: 1.0988 }` 打分，评分路径与界面同源（`vocab/lo/hi`）：

```bash
node tools/simulate-test.cjs 3000                   # 种子基址 1000（与拟合折同种子，但按当前交付常量原样评）
node tools/simulate-test.cjs 3000 --seedbase=900000 # 完全独立批
```

| 批次 | 偏差 | MAE | RMSE | P90 误差 | 95% 区间实测覆盖 | 平均宽度 |
|---|---|---|---|---|---|---|
| 种子 1000（N=3000） | +26 词 | 812 | 1035 | 1676 | **95.4%** | 4018 词 |
| 种子 900000（N=3000） | +21 词 | 818 | 1046 | 1730 | **95.2%** | 4013 词 |

两批覆盖率都落在名义 95% 附近，§2 的结论在交付路径上可复现；「实测覆盖 94.6%」
（界面上那一行脚注）取的是 §2 验证折的保守值，本轮两批实测为 95.2%–95.4%，脚注不算夸大。

本轮实测暴露、如实记录的两个短板（**未**通过改判据或加宽系数硬凑）：

- **最高真值段覆盖在两批间不稳定**：种子 900000 的 D10 覆盖 80%（与 §5 所述一致），
  而种子 1000 同一批切分的 D9 为 96%、D10 为 100%——每段仅约 300 人，段级覆盖率的
  抽样噪声本身就接近 ±5 个百分点，顶部水平的区间保证仍只能算"大致成立"。
- **同一批人上 v2 的偏差随种子漂移明显**：-326（种子 1000）vs -373（种子 900000），
  量级 ~47 词；对比之下 v3 的偏差 +26 / +21 稳定得多。这说明 §3 里 v2/v3 对比的
  "倍数关系"（1.54–1.56 倍）稳健，但 v2 偏差的具体数值不宜当真值引用。

方法学依据见 `docs/notes/NOTES.md`「2026-09-30 第四轮」：验证在交付路径上做（MAPIE
conformalize 只吃校准集）、95% 只作入参不反调（有限样本修正 `q=(1-α)(1+1/n)`）、
诊断常量冻结为历史值（statsmodels results/* 模式）。
